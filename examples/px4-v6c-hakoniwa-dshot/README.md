# examples/px4-v6c-hakoniwa-dshot

PX4 on the emulated Pixhawk 6C with DShot600 ESCs, their telemetry and a motor stop: [docs/dshot.md](../../docs/dshot.md#pixhawk-6c).

List the PX4 files with `../px4-hakoniwa/get-sd-file.py sd.img --list`; copy the latest log without mounting the
image with `../px4-hakoniwa/get-sd-file.py sd.img --newest '*.ulg' flight.ulg`.
